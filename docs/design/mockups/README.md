# PeeGeeQ Cache management UI mockups

Open [peegeeq-cache-management-ui-mockups.html](peegeeq-cache-management-ui-mockups.html) in a browser to review the interactive screen designs.

The mockup includes:

- Overview
- Cache Setups
- Namespaces
- Key Browser and Key Details
- Counters
- Locks
- Pub/Sub
- Monitoring
- Settings
- setup registration, bulk entry deletion, and forced lock-release dialogs

The data is illustrative. The file makes no API or network calls and is not production UI code. Product behavior is defined in [the management UI design](../PEEGEEQ_CACHE_MANAGEMENT_UI_DESIGN.md), and the complete backend contract is defined in [the management API design](../PEEGEEQ_CACHE_MANAGEMENT_API.md).
